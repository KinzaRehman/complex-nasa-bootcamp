## Limits
This uses two different API's. 
1. Nasa (https://data.nasa.gov/docs/legacy/gvk9-iz74.json)
- no Api key needed 
- needs a backend
- Need Cors.io for live server
    
2. Weather (https://api.weatherapi.com/v1/current.json)
- Api key needed 
- no backend needed
